# ☁️ 한글 어휘 노트

단어를 입력하면 네이버·다음 국어사전 링크가 나오고, 검색한 단어를 날짜별로 모아 보는 웹앱이에요.
**여러 기기(폰·PC)에서 같은 단어장**을 쓸 수 있어요.

- 단어 검색 → 네이버/다음 국어사전 바로가기
- 날짜별 정리, 날짜 옮기기
- 외운 단어 체크(줄긋기), 중요한 단어 별표, 단어별 뜻 직접 입력
- 기기 간 동기화 (Vercel + Upstash Redis)

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 전체 (빌드 과정 없음) |
| `api/sync.js` | 동기화 서버 (Vercel 서버리스 함수) |
| `package.json` | 서버 함수가 쓰는 패키지(`@upstash/redis`) |
| `manifest.json`, `sw.js` | 홈 화면에 설치하는 웹앱(PWA) 설정과 오프라인 저장 |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |

## 배포 방법

### 1. GitHub에 올리기
1. GitHub에서 **New repository**로 저장소를 만들어요. (예: `vocab-note`)
2. 이 폴더에서 아래 명령어를 실행해요.

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/내아이디/vocab-note.git
git push -u origin main
```

터미널이 어렵다면 저장소 화면의 **uploading an existing file**로 폴더 안 파일을 올려도 돼요.
(`api` 폴더는 폴더째로 올려야 해요. 폴더 구조가 그대로여야 동작해요.)

### 2. Vercel에 배포하기
1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인해요.
2. **Add New… → Project**에서 저장소를 **Import** 해요.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 두고 **Deploy**를 눌러요.

여기까지만 해도 앱은 열리지만, 아직 동기화는 안 돼요. 아래 3~4번을 해야 해요.

### 3. 저장소(Redis) 연결하기
1. Vercel 프로젝트 화면에서 **Storage** 탭을 열어요.
2. **Create Database**에서 **Upstash (Redis)** 를 골라 만들고, 이 프로젝트에 **Connect** 해요.
3. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 같은 환경변수가 자동으로 들어가요. (`UPSTASH_REDIS_REST_URL/TOKEN` 이름으로 들어가도 코드가 둘 다 읽어요.)

화면 이름은 Vercel 업데이트에 따라 조금 다를 수 있어요. 헷갈리면 Vercel 대시보드의 Storage 또는 Marketplace에서 Upstash Redis를 찾아 프로젝트에 연결하면 돼요.

### 4. 비밀번호 정하고 다시 배포하기
1. **Settings → Environment Variables**에서 아래 변수를 추가해요.
   - 이름: `VOCAB_PASSWORD`
   - 값: 길고 알아보기 어려운 나만의 비밀번호 (예: 12자 이상)
2. **Deployments** 탭에서 가장 최근 배포의 **Redeploy**를 눌러요. (환경변수는 다시 배포해야 적용돼요.)

### 5. 앱에서 동기화 켜기
1. 배포된 주소를 열고 제목 아래 **동기화 켜기**를 눌러요.
2. 4번에서 정한 비밀번호를 입력하고 **연결**을 눌러요.
3. "☁️ 동기화됨"이 뜨면 성공이에요. 다른 기기에서도 같은 주소로 들어가 같은 비밀번호를 입력하면 같은 단어장이 보여요.

## 홈 화면에 앱으로 설치하기 (웹앱)
배포가 끝난 주소를 열고 아래처럼 하면 주소창 없이 앱처럼 열려요. (HTTPS 주소에서만 설치할 수 있는데, Vercel 주소는 기본으로 HTTPS예요.)

- **아이폰(Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)**: 오른쪽 위 메뉴 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **PC(Chrome·Edge)**: 주소창 오른쪽의 **설치** 아이콘 클릭

설치한 앱은 인터넷이 없어도 열려요. (동기화는 연결되면 자동으로 해요.)
화면을 고쳐서 다시 배포하면 인터넷이 될 때 최신 버전으로 바뀌어요. 바뀌지 않으면 앱을 완전히 닫았다가 다시 열어 보세요.

## 동기화 방식
- 단어마다 마지막 수정 시각을 기록하고, 기기끼리 만나면 **더 최근에 수정한 쪽**이 남아요.
- 한 기기에서 단어를 추가·삭제·체크·별표·뜻 수정하면 약 1초 뒤 서버로 올라가고, 다른 기기는 화면을 다시 볼 때나 30초마다 가져와요.
- 인터넷이 없어도 쓸 수 있어요. 연결되면 자동으로 합쳐져요.
- 삭제한 단어의 기록은 90일 동안 보관해서 다른 기기에서 되살아나는 일을 막아요.

## 주의
- 비밀번호 하나로 전체 단어장을 보호하는 단순한 구조예요. 혼자 쓰는 단어장 용도로 만든 거라 길고 어려운 비밀번호를 쓰세요.
- 비밀번호는 각 기기 브라우저에 저장돼요. 공용 컴퓨터에서는 쓴 뒤 **연결 해제**를 눌러 주세요.
- 비밀번호를 바꾸려면 Vercel에서 `VOCAB_PASSWORD`를 바꾸고 Redeploy한 뒤, 각 기기에서 새 비밀번호로 다시 연결하세요.
- 동기화를 켜지 않으면 예전처럼 이 브라우저에만 저장돼요.
- 글꼴은 Google Fonts(고운돋움, 주아)를 불러와요. 불러오지 못하면 기본 한글 글꼴로 보여요.
